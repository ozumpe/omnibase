OmniBase, an open-source experiment

A forecaster that writes its own code, and has to prove it on data it has never seen.

Each week it reads public fuel prices, writes a new forecasting rule, and runs it through an exam it cannot see or change. If the rule beats the simple baseline, it opens a pull request. A human decides whether to merge.

It proposes. History grades it. You merge.

    The loop

    1. ProposeA model writes a new rule on its own branch.
    2. SandboxThe code runs in a locked container, never in the engine itself.
    3. ExamIt must beat the baseline by 10% on held-out history it was never shown.
    4. Pull requestOnly a rule that passes every gate opens one, after its own review.
    5. Human mergeThe engine cannot merge. Promotion follows only a merge it sees a person make.
